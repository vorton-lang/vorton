## 记号约定

- `monospace` 表示关键字、标识符或代码片段
- EBNF 使用 `::=` 定义产生式，`|` 表示选择，`?` 表示可选，`*` 表示零或多个，`+` 表示一或多个
- `⟨name⟩` 表示元变量（实际构造的占位符）
- 类型规则使用标准推导记法：前提在横线上方，结论在下方
- `Γ` 表示类型环境，`⊢` 表示类型判断，`/` 分隔类型和 effect row
- `τ`、`σ`、`ρ` 表示类型；`ε` 表示 effect row；`α`、`β` 表示类型变量
